# Enrollners

One-page website for **Enrollners**, a marketing agency built exclusively for educational institutes in Pakistan: study-abroad consultancies, coaching and test-prep academies, private schools and colleges.

Plain HTML, CSS and a little JavaScript in a single `index.html`. No build step. Deployed with GitHub Pages.

## Before going live

- **Results section:** the figures are labelled as example outcomes. Swap in real client results as soon as you have them.
- **Contact form:** get a free access key from [web3forms.com](https://web3forms.com) and paste it into `WEB3FORMS_KEY` near the bottom of `index.html`. Until then, submitting opens the visitor's email app with the details pre-filled to contact@enrollers.com.
- **Custom domain:** to use enrollers.com, add it under Settings → Pages → Custom domain and point the domain's DNS to GitHub Pages.

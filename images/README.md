# Website images

Every photo on the site lives in this folder. To change one, upload a new file **with the same file name** (for example, a new `hero.webp`) and Vercel will redeploy the site with it automatically.

| File | Where it appears | Best shape |
|---|---|---|
| `hero.webp` | Background of the top (hero) section | Wide landscape, about 1600 × 1100 |
| `college.webp` | "The problem" section, under the paragraph | Landscape, 16:10 |
| `study-abroad.webp` | "Who we serve" card: Study-abroad consultancies | Landscape or portrait, subject near the middle |
| `academy.webp` | "Who we serve" card: Coaching & test-prep academies | Same as above |
| `school.webp` | "Who we serve" card: Private schools | Same as above |
| `graduates.webp` | "Who we serve" card: Colleges & universities | Same as above |
| `consultation.webp` | Results: study-abroad consultancy example | Landscape |
| `exam-prep.webp` | Results: test-prep academy example | Landscape or portrait |
| `classroom.webp` | Results: private school example | Landscape |

## Tips

- Keep each file under about 300 KB so the site stays fast. Export as `.webp` (or `.jpg`), around 800–1600 px wide.
- Photos of your own clients, campuses and students will always beat stock photos. Get written permission before using photos of real students, especially children.
- If you use a different file name or format (for example `hero.jpg`), update the matching `images/...` path in `index.html` as well.
